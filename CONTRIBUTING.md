# Contributing to Groupor Frontend

Thank you for your interest in contributing to Groupor!

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/groupor-frontend.git
   cd groupor-frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a new topic branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Standards

- **Code Quality**: Ensure all code passes linting (`npm run lint`) and formatting (`npm run format`).
- **Semantic HTML & SEO**: Use appropriate HTML5 semantic elements, descriptive alt tags, and preserve existing structured data schemas.
- **Component Design**: Keep UI components modular and responsive across mobile, tablet, and desktop viewports.

## Submitting Pull Requests

1. Commit your changes with clear, descriptive commit messages.
2. Push your topic branch to your fork.
3. Open a Pull Request against the `master` branch.
4. Describe the changes, motivation, and any testing performed.
